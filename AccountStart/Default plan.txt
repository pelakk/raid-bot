# ================================================================================================
#  RSLBot - ACCOUNT START PLAN
# ================================================================================================
#
# WHAT IT DOES
#   While the Farm account list is ON (General tab, Farmer option), the bot plays the campaign
#   and collects the start rewards. It reads the account level in Raid and changes its settings when
#   the account reaches the levels written below. This lets a new account turn on features little by
#   little: champion replacement once there are enough champions, arena, farming the campaign,
#   dungeons... At the level chosen in the "until" list of the Farm row, the account start stops and
#   your own settings come back.
#
# PLAN FILES
#   - Plans are the .txt files of the AccountStart folder, in the RSLBot folder (like the AutoSell and
#     Settings folders). The Farm row of the General tab works like the AutoSell rows of the Bastion tab:
#     [OFF / ON / Edit]  Farm  [plan]  until  [account level]
#     Choose the plan in the plan list, the level in the "until" list, then ON.
#   - To change a plan: stop the bot, choose the plan in the list, then Edit: the plan opens in your text
#     editor (Notepad). Change it and save it.
#   - To create your own plan: Edit, then "Save as" (File menu of Notepad) with a new name, for example
#     "My plan.txt". Notepad saves it in the same folder (AccountStart), so it shows in the plan list at once.
#     Then choose it in the list.
#   - "Default plan.txt" comes with RSLBot and is replaced by each new version: change your own copy, not it.
#
# HOW TO WRITE A STEP
#   One step per line:      level : setting name = value
#   Example:                15 : Campaign Champions replacement number = 3
#   - level: account level (1 to 100). Several lines can have the same level.
#   - setting name: written exactly as in the files of the Settings folder (open "Account start.txt"
#     with Notepad: the text before the colon on each line is the setting name). Upper/lower case ignored.
#   - value: the text after the colon in those files. For a drop-down list, the value must be one of
#     its choices (ON, OFF, Off, 1, 2, 3, NO...). Upper/lower case ignored.
#   - Lines starting with # are comments; empty lines are ignored.
#
# WHEN STEPS ARE APPLIED
#   - The account level is read after each battle and at the Bastion.
#   - Each step is applied once, when the level reaches it, in level order. Every change is shown
#     in cyan in the log. A step whose level is already passed is not applied again, even after a
#     restart of the bot (set the Farm list OFF then ON to start the plan again).
#   - The plan can be changed while the bot runs: it is read again at each level check.
#   - A badly written line is shown in orange in the log and ignored; the other lines still work.
#   - At the level chosen in the "until" list of the Farm row your own settings come back, and the
#     steps from that level on are not applied.
#
# SETTINGS MADE FOR THE PLAN
#   Account Start Campaign Farm = N
#       Each new campaign stage won is replayed N times (experience, artifacts) before the next stage.
#       0 = no farm. The last stage of a region is not farmed.
#   Number of Defeats in a row to downgrade stage number = N   (NO, 1 to 10)
#       After N defeats in a row, the campaign goes back one stage. Default during the account start: 1.
#   Number of Victories in a row to upgrade stage number = N   (NO, 1 to 10)
#       After going back, the stage lost is tried again after N victories. Default: 3.
#       When a campaign farm is running, its number is used instead.
#   Account Start Market Slots = N   (0 to 6, default 6)
#       Market slots unlocked with silver at each Market visit, up to slot N. On a new account the 7th slot asks for
#       gems: the bot never goes past the 6th and never accepts a price in gems.
#   Account Start Leader = Athel, Elhain, Kael or Galek   (optional)
#       The leader is the starter champion of the account: the bot trains him first (rank up, brews, artifacts,
#       skills) and uses him in the Classic Arena defence.
#       - Account that starts from zero (tutorial not done): with this line, the bot chooses this champion in the
#         tutorial ("Choose your first Champion") and trains him; without this line, it chooses Athel.
#         Write it at level 1, for example:  1 : Account Start Leader = Kael
#       - Account already started (the starter was chosen before): leave this line out, the bot finds the starter
#         the account has and trains him (the best one if it has several). With this line, the bot trains the
#         champion written here, so it must be the one the account has.
#   Account Start Champion Collection = N   (0 = off)
#       The champion collection is extended (Champions, "+" at the end of the list, 10 places) until N places, paid with
#       silver only (120,000; never the gems button). The minimum silver of the settings does not apply during the account start.
#   Account Start Farm Until Core Rank = N
#       While Athel or Warpriest is under N stars, the campaign does not go further: the stage won is
#       replayed (food champions, experience) until both are ranked up. 0 = off.
#       Athel and Warpriest never leave the campaign team during the account start.
#
# USEFUL SETTINGS (name = possible values)
#   Campaign Champions replacement number = Off, 1, 2, 3     (food champions replaced when maxed)
#   Campaign Champions replacement rarity / rank               (same values as in the bot)
#   Classic Arena Battles switch = ON, OFF
#   Tag Team Arena Battles switch = ON, OFF
#   Dungeons Battles menu = ON, OFF    with  Dungeon Name, Dungeon Stage, Number of Dungeon Battles to do
#   Demon Lord Battles switch = ON, OFF
#   Faction War Battles switch = ON, OFF
#   Doom Tower Battles switch = ON, OFF
#   Minimum Energy for Battles = number
#   Tavern switch = On, Off    with  Champion to level Rank choice = Until Rank 3, Until Rank 4...,
#       Sacrifice rank 1 champions checkbox, Exclude rare / ascended / fusion champions checkbox = On, Off
#   Portal switch = On, Off    with  Number of champions to summon = 10, 20... (Mystery Shards; during the
#       account start the Portal is also used when there are not enough champions to replace)
#   Any other setting of the Settings files can be used the same way.
#   Settings that cannot be changed here: login data, emulator, Account Start.
#
