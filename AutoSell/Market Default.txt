// =====================================================================================
// MARKET DEFAULT - RSLBot v8.6 - rules for the artifacts the Market buys
// =====================================================================================
// HOW IT WORKS
// - Bastion > Market > Manage > "Buy Artifacts": choose this file (or any AutoSell rules file).
//   Edit opens the rules editor. Buy Artifacts must be ON.
// - At each Market visit, the bot reads every artifact offered and checks the "Buy" lines of
//   the file, from top to bottom. The first Buy line that matches decides: the artifact is
//   bought if its price is not above the line's MaxPrice and if the silver left stays above
//   "Minimum silver to keep".
// - A Buy line uses the same conditions as Keep / Sell / Upgrade lines: Set, Rank, Rarity,
//   Type, Main, Sub, n*Sub, Faction, Weight.
// - Market artifacts are level 0: Epic = 2 substats, Legendary = 3, Mythical = 4.
//   So "3*Sub = ..." never matches an Epic.
// - MaxPrice = the most silver a line pays (1M = 1,000,000, 750K = 750,000).
//   A Buy line without MaxPrice uses "Max silver per artifact" of Market Management.
// - Weight: "Weight >= N" (Panda weight, 0..110), beside Sub or in place of it.
// - Safety: the Market never buys an artifact that a Sell line would sell at once
//   (a Sell line of this file, or of the Artifacts storage rules file). The rules editor
//   shows such a Buy line in red: "wrong Buy line".
// - Statistics: Market Management > Stats (what was bought since the bot started).
//
// BUY LINES IN THE STORAGE RULES FILES
// - "Buy" is an action like Keep, Sell and Upgrade: Buy lines can also be written in the
//   storage rules files (End Game, Mid Game, ...), for example next to the lines of each set:
//       Buy,  Set = Speed, Rank = 6, Rarity = Epic, Type = B, Main = SPD, MaxPrice = 1M
//       Keep, Set = Speed, Rank = 6, Type = B, Main = SPD
//   Then choose that file in the Market too: one file for buying and keeping.
// - Only the Market reads Buy lines. The storage, the Inbox and the battles skip them,
//   so a Buy line never changes what the storage keeps or sells.
// - For now this separate Market file is the simplest way: it can be changed without
//   touching the storage rules.
//
// SET CHOICE (advanced account, players' advice Reddit 2025-2026, not official numbers)
//   Priority 1: Speed, Savage, Regeneration           (ON in this file)
//   Priority 2: Reflex, Provoke, Cursed               (OFF: remove the // to use them)
//   Priority 3: Stun, Lifesteal (Legendary only)      (OFF)
//   Other sets: only exceptional pieces               (OFF)
//   6* only (5* or less ignored); flat ATK / DEF / HP main stat on gauntlets or chestplate ignored;
//   Epic: right main stat + good substats; Legendary / Mythical: 3 good substats.
//   Prices: Epic up to 1M, Legendary and Mythical up to 2M.
// =====================================================================================
